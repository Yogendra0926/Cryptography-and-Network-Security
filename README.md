# Cryptography and Network Security 

A comprehensive collection of **14 practical experiments** covering cryptographic algorithms, encryption and decryption, hashing, digital signatures, network security, password auditing, and secure authentication.

This repository demonstrates the practical implementation of fundamental cybersecurity concepts using Python, OpenSSL, CrypTool, Wireshark, John the Ripper, and Linux-based security tools.

## About This Repository

The purpose of this repository is to understand and implement various cryptographic techniques and network security mechanisms through hands-on experiments.

The experiments cover classical cryptography, modern encryption algorithms, public-key cryptography, secure communication protocols, network traffic analysis, and password security assessment.

## Technologies and Tools Used

- **Programming Language:** Python
- **Development Environment:** Visual Studio Code
- **Cryptographic Tools:** OpenSSL, CrypTool
- **Network Analysis:** Wireshark
- **VPN Software:** Proton VPN
- **Password Auditing:** John the Ripper
- **Secure Authentication:** OpenSSH
- **Operating Systems:** Windows, Linux

## List of Experiments

| Exp. No. | Experiment Title |
|---|---|
| 01 | Implement Caesar, Vigenère, and Rail Fence ciphers to encrypt and decrypt plaintext, and compare their working and effectiveness. The given plaintext is "HELLO WORLD". |
| 02 | Perform frequency analysis on classical cipher texts and analyze their vulnerability to cryptanalysis attacks using CrypTool. |
| 03 | Encrypt sample data using DES and AES algorithms, and compare their security features and performance. |
| 04 | Generate RSA public and private key pairs and perform secure file encryption and decryption using OpenSSL. |
| 05 | Generate SHA-256 hash values, create digital signatures, and verify their authenticity using OpenSSL. |
| 06 | Create a self-signed X.509 digital certificate and analyze its attributes, validity, and security features. |
| 07 | Implement RSA and Diffie–Hellman algorithms to demonstrate secure key exchange and public-key cryptography using VS Code. |
| 08 | Develop an application to secure text messages using AES encryption and SHA-256 hashing using VS Code. |
| 09 | Implement password hashing with and without salting, and evaluate resistance against common password attacks using VS Code. |
| 10 | Capture HTTPS network traffic using Wireshark and analyze the TLS handshake, digital certificates, and cipher suites. |
| 11 | Capture and analyze encrypted VPN traffic using Wireshark, and compare it with unencrypted network communication. |
| 12 | Analyze captured network packets to identify secure and insecure communication protocols and their security implications. |
| 13 | Perform password auditing using John the Ripper and evaluate password strength against dictionary and brute-force attacks. |
| 14 | Generate SSH/RSA key pairs and configure passwordless authentication between Linux systems. |

## Key Learning Outcomes

Through these experiments, the following concepts are explored:

- Implementation of classical and modern cryptographic algorithms.
- Understanding symmetric and asymmetric encryption techniques.
- Generation and verification of cryptographic hashes and digital signatures.
- Implementation of RSA and Diffie–Hellman cryptographic techniques.
- Analysis of digital certificates and secure communication protocols.
- Examination of HTTP, HTTPS, TLS, and VPN network traffic.
- Evaluation of password security using hashing, salting, and auditing tools.
- Configuration of secure remote authentication using SSH/RSA keys.

## Security and Ethical Considerations

All experiments are intended for educational and authorized security testing purposes only.

Password auditing, network packet capture, and cryptographic testing should be performed only on systems, networks, and data for which appropriate authorization has been obtained.

Private keys, real passwords, and sensitive network information should never be committed to public repositories.
